# Experiment 9: Create a Virtual Hard Disk

## Aim
To create a virtual hard disk and allocate storage using VMware Workstation.

## Procedure
1. Open VMware Workstation, right-click the VM and open **Settings**.
2. Click **Add** (Add Hardware Wizard) and select **Hard Disk**; choose SCSI and click Next.
3. Choose **Create a new virtual disk**.
4. Set the disk size to 2.0 GB and select **Split virtual disk into multiple files**.
5. Give the disk a file name and click Finish.
