# Experiment 13: IaaS: Resource Group (Azure)

## Aim
To demonstrate IaaS by creating a resource group in Azure and configuring minimum CPU, RAM and storage.

## Procedure
1. Create/sign in to a Microsoft Azure account.
2. Go to **Resource groups** and click **Create**.
3. Select subscription, enter a resource group name and region.
4. Click **Review + create**, then **Create**.
5. Create a virtual network inside the resource group (for the VM in Exp 14).
