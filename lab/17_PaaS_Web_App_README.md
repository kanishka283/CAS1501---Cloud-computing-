# Experiment 17: PaaS: Host a Simple Web Application

## Aim
To create a simple web application (Python/Java) and host it on a public cloud (Azure App Service) to demonstrate PaaS.

## Procedure
1. Go to **App Services > Create > Web App**.
2. Choose resource group, web app name, runtime stack (Python 3.x) and region; select Linux.
3. Review + create; wait for deployment.
4. Deploy `app.py` (see this folder) via Deployment Center / VS Code.
5. Open the web app **Default domain** URL in a browser.
