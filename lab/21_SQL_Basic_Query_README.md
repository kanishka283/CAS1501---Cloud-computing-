# Experiment 21: SQL Storage Service and Basic Query

## Aim
To create a SQL database service and run a basic query to demonstrate DaaS.

## Procedure
1. Azure > **SQL databases > Create**; select resource group and server name.
2. Networking: allow Azure services and resources to access this server (add your client IP).
3. Additional settings: use existing data = **Sample** (AdventureWorksLT).
4. Review + create; wait for deployment.
5. Open **Query editor**, sign in with SQL authentication.
6. Run the queries in `queries.sql`.
