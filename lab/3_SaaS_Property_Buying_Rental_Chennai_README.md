# Experiment 3: Property Buying & Rental, Chennai (SaaS)

## Aim
To create a property buying and rental application for Chennai city to demonstrate SaaS.

## Procedure
1. Go to zoho.com and log in to your account.
2. Open Zoho Creator and click **Create Application** (start from scratch).
3. Enter the application name: **Property Buying & Rental**.
4. Create a new form and add the fields needed for the system.
5. Save the form, open **Access Application**, and add one sample record.
6. The cloud application is now live as a SaaS service.
