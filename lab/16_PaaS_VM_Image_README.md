# Experiment 16: PaaS: Create and Configure a New VM Image

## Aim
To demonstrate PaaS by creating and configuring a new VM image in a public cloud.

## Procedure
1. In Azure, open the running VM and run **Capture** (or create a managed image / snapshot).
2. Name the image and select the resource group.
3. Review + create.
4. Create a new VM from the image and verify it boots.
