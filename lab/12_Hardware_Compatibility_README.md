# Experiment 12: Change Hardware Compatibility of a VM

## Aim
To change the hardware compatibility of an already created VM (via clone).

## Procedure
1. Power off the VM; go to **VM > Manage > Change Hardware Compatibility**.
2. Choose to **Clone the virtual machine** (or create a new one).
3. Select the target hardware version.
4. Complete the wizard and power on the new VM.
