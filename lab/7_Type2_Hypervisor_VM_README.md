# Experiment 7: Virtualization with a Type-2 Hypervisor

## Aim
To demonstrate virtualization by installing a Type-2 hypervisor and creating a VM with a guest OS.

## Procedure
1. Download and install VMware Workstation (Type-2 hypervisor).
2. Download an Ubuntu or Tiny Core ISO image.
3. In VMware Workstation choose **File > New Virtual Machine**.
4. Complete the basic configuration (ISO, guest OS, name, location).
5. Finish to create the VM, then **Power on** to launch it.
