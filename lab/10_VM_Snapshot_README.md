# Experiment 10: Snapshot of a VM

## Aim
To create a snapshot of a VM and test it by restoring the previous version.

## Procedure
1. Open VMware Workstation and power on the VM.
2. Create a few files on the VM desktop.
3. Select **VM > Snapshot > Take Snapshot**, name it and click Take.
4. Delete the files you created.
5. Open **Snapshot Manager** and **Go To** the snapshot.
6. Verify the deleted files are restored.
