# Experiment 15: IaaS: Remote Connection to the VM

## Aim
To connect remotely to the Azure VM, launch it and run it on your desktop.

## Procedure
1. Open the VM > **Connect > RDP** and download the RDP file.
2. Open the RDP file on your desktop and enter the admin credentials.
3. Accept the certificate prompt.
4. The Windows VM desktop opens on your machine.
5. Optional: resize the VM (VM > Size) and observe the change.
