# Experiment 14: IaaS: Create a Virtual Machine (Azure)

## Aim
To create a virtual machine in Azure and configure the required memory and CPU.

## Procedure
1. Go to **Virtual machines > Create > Azure virtual machine**.
2. Select the resource group, VM name, region and a Windows image.
3. Choose a small size (e.g. B1s/B2s: 1-2 vCPU, 1-4 GB RAM).
4. Set administrator username and password.
5. Review + create and wait for the deployment to complete.
