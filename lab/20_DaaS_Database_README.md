# Experiment 20: Database as a Service

## Aim
To demonstrate DaaS by creating and configuring a managed database in a public cloud.

## Procedure
1. In Azure go to **SQL databases > Create**.
2. Choose resource group, database name and create a new server (SQL authentication).
3. Pick the cheapest compute tier.
4. Review + create and wait for deployment.
