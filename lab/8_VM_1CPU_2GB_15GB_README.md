# Experiment 8: VM with 1 CPU, 2 GB RAM, 15 GB Disk

## Aim
To create a VM with 1 CPU, 2 GB RAM and a 15 GB disk using Type-2 virtualization software.

## Procedure
1. Open VMware Workstation and start **New Virtual Machine** (Custom).
2. Select the ISO and guest OS.
3. Set processors: 1 CPU, 1 core.
4. Set memory: 2048 MB (2 GB).
5. Set maximum disk size: 15 GB.
6. Finish and power on the VM.
