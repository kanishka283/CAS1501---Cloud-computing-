# Experiment 19: Storage Service and Public Accessibility

## Aim
To create a storage service and check the public accessibility of the stored file (static website).

## Procedure
1. Open Azure **Storage accounts > Create**; enter resource group and account name; Review + create.
2. Open the account > **Static website** > **Enabled**; enter `index.html` and `404.html`.
3. Open **Containers > $web** and upload `index.html` and `404.html` (provided in this folder).
4. Return to Static website and open the **Primary endpoint** link.
5. Verify the page loads publicly (try in a private/incognito window).
