# Experiment 18: Storage as a Service

## Aim
To demonstrate Storage as a Service by creating and configuring storage in a public cloud.

## Procedure
1. Go to **Storage accounts > Create**.
2. Choose resource group, unique account name, region and redundancy (LRS).
3. Review + create.
4. Open the account, create a blob container and upload a file.
