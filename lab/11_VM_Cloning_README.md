# Experiment 11: Cloning of a VM

## Aim
To create a clone of a VM and test it by loading the cloned VM.

## Procedure
1. Power off the VM; go to **VM > Manage > Clone**.
2. Click Next and choose the clone source (current state or snapshot).
3. Select **Create a full clone**.
4. Name the clone and click Finish.
5. Power on the cloned VM and verify its contents.
